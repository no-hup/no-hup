### 🏗 Architecture & Design

- Clean Architecture — not as a religion, but because it makes things easier to change
- Modularization & layered design
- Pragmatic about SOLID: I follow the principles that make a system genuinely scalable and maintainable. Not all five, not always by the book — but always with intent.

The goal every time I write code: it should be clean, simplistic, and easy for the next developer to pick up. Code that doesn't need to be rewritten six months later. That's the real success metric.

### 🤖 AI evaluation

- Contract work for research labs I can't name. A steady run of tasks, not one showcase
- A task is usually a real feature or a real bug. I set the repo up in Docker, with the services it needs
- I write a reference solution and a grader. A fix that's genuinely right should pass, even when it isn't the approach I would have taken
- Doing nothing should fail. So should a change that only makes the tests go green. If a score looks off, I read the run and fix the task or the grader
